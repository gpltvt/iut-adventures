# IUT Adventures

> **Projet en cours de développement** — de nouveaux personnages et scènes arrivent bientôt !

Jeu textuel à choix multiples développé dans le cadre du BUT1 (2025-2026).  

## Principe du jeu

- Fais les bons choix pour progresser et atteindre la victoire
- Un mauvais choix peut mener au **Game Over**
- Des **événements aléatoires** peuvent surgir à tout moment et te poser des questions surprises
- Une **carte de l'IUT** est disponible en cours de partie (touche `m`)
- Le jeu est disponible en **français et en anglais**

## Personnages jouables

| Touche | Personnage         | Statut           |
|--------|--------------------|------------------|
| `M`    | Mme MELEC          | Disponible       |
| `D`    | Mme La DAUPHINE    | En développement |

| `A`    | Mr ATHE            | Disponible       |
| `C`    | Mr COCOT           | En développement |

### Compiler


# Windows
