Game developed by PLAETEVOET Gaëlle and MAHIEU Ella

As part of the beginning of our SAÉ, we first worked on creating the story of our game.
To match our theme, we created a multiple-choice question system (MCQ) that allows the player to progress through the story and find the colleague they are looking for.
By the end of the week, we would like to develop additional characters to give more variety to the player and provide a complete gameplay experience.

The structure of our code is therefore composed of:
→ A function responsible for retrieving the file names of each scene
→ A second structure that helps keep the code easy to maintain while linking the different scenes according to the player’s choices
→ Various functions that record player inputs and prevent any issues with the input buffer
→ Functions that were created to ask the player questions again if their input is incorrect

Take a look at the code yourself, Ella did her best to comment it clearly, and not everything can be summarized here!
